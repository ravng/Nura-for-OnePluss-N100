CRITICAL DISCOVERY
------------------
Ubuntu Focal mir-demos 1.7.1 is not compatible enough with the UBports Mir
1.8.2 libraries for this test. miral-shell/miral-kiosk started, but connecting
either a legacy Mir client or a Wayland client caused status 139. Replacing it
with the exact UBports mir-demos 1.8.2 build fixed the crash.

HWC overlays are disabled in the visible smoke launcher. This forces the
Wayland SHM surface through Mir's Adreno GL compositor instead of testing an
HWC direct-scanout optimization.

The following warnings are non-fatal for the proven path:
- eglSubDriverAndroid.so not found
- libadreno_app_profiles.so not found
- libminisf.so not found

Do not hide or special-case those warnings. EGL, GLES 3.2, HWC2, display
composition, and a visible client all initialized afterward.

EARLIER MESA RESULT
-------------------
Mesa 26.2.5 Turnip built with freedreno-kmds=kgsl still provides a useful
low-level oracle:

  VK_DRIVER_FILES=/home/nura/gpu-build/build/src/freedreno/vulkan/freedreno_devenv_icd.aarch64.json \
  TU_DEBUG=startup vulkaninfo --summary

Expected:
  Found compatible device '/dev/kgsl-3d0'
  Turnip Adreno (TM) 610

That route cannot accelerate current Phoc: the downstream display is
/dev/dri/card0 while Turnip uses /dev/kgsl-3d0, and wlroots cannot join the
KGSL allocator to this DRM display. The working route is Halium/libhybris/Mir.

SAFETY AND REMAINING INTEGRATION
--------------------------------
- Keep WLR_RENDERER=pixman in the default greeter and Phosh session.
- Keep the Ubuntu root side-by-side until login, lock/unlock, touch, and resume
  are stable under the accelerated compositor.
- Before every Android LXC start, remove stale /dev/__properties__/* and
  /dev/socket/*; stale Android property files cause an init reboot loop.
- Runs start many Android vendor services. Keep experimental runs controlled;
  modem/Wi-Fi service interaction remains a device-crash risk.
- Never replace the known-good boot/root images merely to test this path.

Next GPU task: package the exact glibc/Halium/libhybris/Mir runtime as a
separate accelerated session, then prove login, touch, lock/unlock,
suspend/resume, repeated app launch, and recovery to Pixman.
